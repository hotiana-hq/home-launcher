# HOTIANA Home launcher source

Build a standalone Android launcher using HOTIANA Home’s app catalogue and responsive grid. Open it from your current launcher to try app search and pins, or select HOTIANA Home Source in Android’s Default Home settings. It supports Android 12 and later.

The source app includes app search and launch, ordered pins, grid density, and Android widget hosting. It installs alongside the official HOTIANA app and stores its own setup. It also keeps small per-app launch counts (by hour of day and weekday or weekend) in its own private preferences to rank suggestions. The official app’s visual themes, hosted services and device connections are not part of this repository.
